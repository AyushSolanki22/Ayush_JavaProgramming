# Level Order Traversal (BFS - Breadth First Search)

---

## Definition

**Level Order Traversal** means visiting the tree **level by level**, from **left to right**.

It is implemented using a **Queue (FIFO)**.

BFS = **Breadth First Search**

---

## Why Queue?

Queue follows **FIFO (First In, First Out)**.

The node that is discovered first should be processed first.

This naturally matches level-by-level traversal.

---

## Intuition

Think of people standing in a queue.

- First person comes out.
- Then his children join the queue.
- Again, the first person in the queue comes out.
- His children join the queue.

Repeat until the queue becomes empty.

---

## Algorithm

1. Create an empty Queue.
2. Insert the root node into the queue.
3. While the queue is not empty:
   - Remove (poll) the front node.
   - Process/Print it.
   - Insert its left child (if present).
   - Insert its right child (if present).
4. Continue until the queue becomes empty.

---

---

# Time Complexity

Every node is visited exactly once.

```
O(n)
```

---

# Space Complexity

Queue may store one complete level.

Worst Case:

```
O(n)
```

---

# Important Queue Operations

```
Queue<TreeNode> q = new LinkedList<>();

q.offer(node);     // Insert
q.poll();          // Remove front
q.peek();          // Front element
q.isEmpty();       // Check empty
q.size();          // Number of elements
```

---

# Level Order Traversal Template

```java
Queue<TreeNode> q = new LinkedList<>();

q.offer(root);

while(!q.isEmpty()){

    TreeNode curr = q.poll();

    // Process current node

    if(curr.left != null)
        q.offer(curr.left);

    if(curr.right != null)
        q.offer(curr.right);
}
```

---

# Level-wise BFS Template (Most Important)

Used in:
- Right Side View
- Zigzag Traversal
- Average of Levels
- Largest Value in Each Row
- Maximum Level Sum
- Many Tree Problems



# Intuition (Comment Style)

```
// Queue helps us visit nodes level by level.
//
// Initially insert the root.
//
// Repeatedly:
// 1. Remove the front node.
// 2. Process it.
// 3. Insert its left child
// 4. Insert its right child.
//
// Since Queue follows FIFO,
// nodes are processed in the same order
// they are discovered, resulting in
// Level Order (BFS) Traversal.
```
