//First Approach : optimised 

class Solution {
    public boolean isPowerOfTwo(int n) {
        return n > 0 && (n & (n - 1)) == 0;
    }
}




Intuition: (n & (n - 1)) == 0

A power of two has exactly one set bit (1) in its binary representation.

When we subtract 1 from a number, the rightmost set bit (the rightmost 1) becomes 0, and all the bits to its right become 1. The bits to its left remain unchanged.

For example, n = 8:

n     = 1000
n - 1 = 0111
        ----
AND   = 0000

Since 8 has only one set bit, subtracting 1 turns that bit into 0, and there are no other set bits remaining in the same positions. Therefore, n & (n - 1) = 0.

But for n = 12:

n     = 1100
n - 1 = 1011
        ----
AND   = 1000

The result is non-zero because n has more than one set bit. Subtracting 1 removes the rightmost set bit, but the other set bits remain unchanged and overlap in both numbers.

Therefore, n & (n - 1) == 0 checks whether n has exactly one set bit. We also need n > 0 because 0 is not a power of two.




//2nd approach : using recurison & division rule (logn T.C)

class Solution {
    public boolean isPowerOfTwo(int n) {
        if(n==0) return false; 

        if(n==1) return true; //final value should be =1
        if(n%2==1) return false; 
        return isPowerOfTwo(n/2);
    }
}

//3rd approach : using while loop and division rule

class Solution {
    public boolean isPowerOfTwo(int n) {
        if(n==0) return false; 

        while(n>1){
            if(n%2==1) return false; 
            n/=2; 
        }
        if(n!=1) return false;
        return true;
    }
}
