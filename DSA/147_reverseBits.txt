
class Solution {
    public int reverseBits(int n) {
        int result = 0;

        for (int i = 0; i < 32; i++) {        //to reverse all 32 bits of a number
            int bit = n & 1;           // Extract last bit
            result = (result << 1) | bit; //Shift ans to left, Append bit to result  ((it appends at last thus))
            n = n>>1;                  // Move to next bit  ((remove rightmost bit))
        }

        return result;
        
    }
}



/*
LeetCode 190: Reverse Bits

Goal: Reverse the order of all 32 bits.

Approach: Extract bits from n and append them to result.

1. Initialize result = 0.
2. Repeat exactly 32 times because an int has 32 bits.
3. Extract the rightmost bit using (n & 1).
4. Shift result left by 1 to make room for the next bit.
5. Append the extracted bit using bitwise OR (|).
6. Shift n right using >>> to process its next bit.  (remove its current rightmost bit that has already been processed for to result)
7. After 32 iterations, return result.

Why it works:
- We extract bits from right to left.
- Every extracted bit is appended to the right of result.
- Thus, the original rightmost bit becomes the result's
  leftmost bit, and the bit order is reversed.

Time: O(1) — exactly 32 iterations.
Space: O(1) — only a few variables.
*/
